《雷神之鎚 III》（Quake III Arena）中的倒平方根速算法（Fast Inverse Square Root）被譽為程式史上的神技。它的核心任務是快速計算：

$$y = \frac{1}{\sqrt{x}} = x^{-1/2}$$

在 1990 年代，硬體的浮點數除法與開根號極其昂貴。這段程式碼透過 **IEEE 754 浮點數結構的對數近似** 與 **牛頓法（Newton's Method）**，以驚人的速度算出精度極高的近似值。

原始 C 語言程式碼如下：

```c
float Q_rsqrt( float number )
{
	long i;
	float x2, y;
	const float threehalfs = 1.5F;

	x2 = number * 0.5F;
	y  = number;
	i  = *(long *) &y;                       // 1. 暴力將 float 的位元視為 integer
	i  = 0x5f3759df - ( i >> 1 );             // 2. 位元位移與魔術數字的對數近似
	y  = *(float *) &i;                      // 3. 轉回 float 格式
	y  = y * ( threehalfs - ( x2 * y * y ) ); // 4. 一次牛頓法疊代修正精度
	return y;
}

```

### **一、 IEEE 754 浮點數的編碼秘密**

要理解魔術數字，必須先了解單精度浮點數（32-bit `float`）在記憶體中的儲存方式：

* **Sign（符號位 $S$）：** 1 bit
* **Exponent（指數 $E$）：** 8 bits（實際指數為 $e = E - 127$，其中 $B = 127$ 為偏置值）
* **Mantissa（尾數 $M$）：** 23 bits（代表小數部分 $M \in [0, 1)$，值為 $m = \frac{M}{2^{23}}$）

因此，一個正浮點數 $x$ 代表的實際數值為：

$$x = (1 + m) \cdot 2^{e} = \left(1 + \frac{M}{2^{23}}\right) \cdot 2^{E - 127}$$

如果我們將這 32-bit 的記憶體資料**不經轉換，直接強轉（Reinterpret）看作 32 位元整數 $I_x$**：

$$I_x = E \cdot 2^{23} + M$$

---

### **二、 對數近似：將乘方轉化為位元運算**

對方程式 $y = x^{-1/2}$ 兩邊取以 2 為底的對數：

$$\log_2(y) = -\frac{1}{2} \log_2(x)$$

代入浮點數的公式 $x = (1 + m) \cdot 2^e$：

$$\log_2(x) = \log_2(1 + m) + e$$

因為尾數 $m \in [0, 1)$，利用對數的泰勒展開近似：**$\log_2(1 + m) \approx m + \sigma$**（其中 $\sigma$ 為自由微調常數，用來最小化近似誤差，最佳值約為 $0.0450465$）。

將近似代入：

$$\log_2(x) \approx m + \sigma + e = \frac{M}{2^{23}} + \sigma + (E - 127)$$

整理一下，注意到整數表示法 $I_x = E \cdot 2^{23} + M$，將其提出：

$$\log_2(x) \approx \frac{1}{2^{23}} (M + E \cdot 2^{23}) + \sigma - 127 = \frac{I_x}{2^{23}} + \sigma - 127$$

這個公式揭示了關鍵：**整數記憶體值 $I_x$ 與對數 $\log_2(x)$ 成線性正比關係！**

---

### **三、 推導魔術數字 $0x5f3759df$**

現在將 $\log_2(y) \approx \frac{I_y}{2^{23}} + \sigma - 127$ 與 $\log_2(x) \approx \frac{I_x}{2^{23}} + \sigma - 127$ 代回核心方程 $\log_2(y) = -\frac{1}{2} \log_2(x)$：

$$\frac{I_y}{2^{23}} + \sigma - 127 \approx -\frac{1}{2} \left( \frac{I_x}{2^{23}} + \sigma - 127 \right)$$

兩邊同乘以 $2^{23}$ 並移項求解 $I_y$：

$$I_y + 2^{23}(\sigma - 127) \approx -\frac{1}{2} I_x - \frac{1}{2} \cdot 2^{23}(\sigma - 127)$$

$$I_y \approx \frac{3}{2} \cdot 2^{23} (127 - \sigma) - \frac{1}{2} I_x$$

請注意這行公式結構：

1. **$\frac{1}{2} I_x$：** 在整數領域，除以 2 就是**位元右移一位（`i >> 1`）**！
2. **$\frac{3}{2} \cdot 2^{23} (127 - \sigma)$：** 這是一個純常數！

這就是這行程式碼的由來：`i = 魔術數字 - (i >> 1)`。

#### **計算常數值：**

若取最優化誤差的 $\sigma \approx 0.0450465$：

$$\text{魔術數字} = \frac{3}{2} \cdot 2^{23} \cdot (127 - 0.0450465) \approx 1597463007$$

將十進位的 $1597463007$ 轉換為十六進位，答案正是：

$$\mathbf{0x5f3759df}$$

透過這一行位元運算，硬體在**單一 CPU 週期內**就得到了 $\frac{1}{\sqrt{x}}$ 的對數粗略估算值！

---

### **四、 牛頓法修正（Newton's Method）**

位元運算給出的只是一個精度約 10% 的初始猜測值 $y_0$。為了精確，程式碼最後使用了**牛頓疊代法**來提昇精度。

要求 $y = \frac{1}{\sqrt{x}}$，等同於求函數 $f(y) = \frac{1}{y^2} - x = 0$ 的根。

牛頓法疊代公式：

$$y_{n+1} = y_n - \frac{f(y_n)}{f'(y_n)}$$

算出導數 $f'(y) = -\frac{2}{y^3}$：

$$y_{n+1} = y_n - \frac{\frac{1}{y_n^2} - x}{-\frac{2}{y_n^3}} = y_n \left( 1.5 - 0.5 \cdot x \cdot y_n^2 \right)$$

這正是程式碼最後一行：
`y = y * ( threehalfs - ( x2 * y * y ) );`

由於對數估算的初始值極度接近真實解，**僅需做一次牛頓疊代**，誤差就會驟降至 **0.175%** 以內，速度比當時硬體的浮點數 FSQRT 指令快了將近 4 倍。
