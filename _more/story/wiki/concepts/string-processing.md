# 字串處理

在文字中搜尋或比對模式的演算法。從暴力搜尋的 O(MN) 到 KMP 的 O(M+N)，關鍵在於善用已經做過的比對。

## 核心特性

- **模式搜尋**：在長字串中找到目標子字串的位置。
- **預處理**：先對模式或文字建立輔助表（如前綴函數），換取搜尋加速。
- **編輯距離**：量化兩個字串的相似程度（插入、刪除、替換的代價）。
- **雜湊與後綴結構**：另可透過滾動雜湊或後綴樹加速各種比對。

## 經典演算法

- [KMP](../algorithms/kmp.md) — O(M+N) 線性時間模式搜尋
- [Levenshtein](../algorithms/levenshtein.md) — 字串編輯距離
