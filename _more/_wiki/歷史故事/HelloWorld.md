# Hello, World!：隨手的問候成了入會儀式

**領域**：數理邏輯與電腦史 | **年代**：1974 | **主角**：Brian Kernighan

---

**趣味點**：布萊恩·柯林漢（Brian Kernighan）在寫 C 語言教學範例時，隨手打出了 Hello, World!。他沒料到這個看似隨意的問候，後來竟成為全球數百萬程式設計師踏入程式世界的「入會儀式」。

1974 年，布萊恩·柯林漢在撰寫 C 語言教材範例時，第一次使用了 "Hello, World!" 這個句子。它原本只是個隨意的測試用文字。

結果它意外成為了程式語言的「第一個程式」傳統：從 C、Python、JavaScript 到 Rust，幾乎每一本程式語言入門書的第一個範例都是它。對數百萬工程師而言，這是他們寫下的第一行字。

**後記**：柯林漢後來還寫了著名的 UNIX 哲學經典《Unix Programming Environment》，並被 IEEE 電腦學會尊稱為「UNIX 之父們」之一。
