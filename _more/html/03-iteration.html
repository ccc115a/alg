03 迭代法 不斷重複同樣的動作，逼近答案

迭代法的精神很簡單：從一個猜測開始，不斷套用同一個更新規則，直到數值不再變化。 收斂的終點叫做「不動點」，而收不收斂、收斂多快，正是迭代法的理論核心。

03.1 定點迭代：xₖ₊₁ = g(xₖ)

把求根問題變成「找不動點」：解 f(x)=0 常常可以改寫成 x = g(x)， 於是迭代 xₖ₊₁ = g(xₖ)。如果序列收斂到 x*，那必然滿足 x* = g(x*)。

收斂定理
若 g 在 x* 附近可微，且 |g′(x*)| < 1，則迭代在 x* 附近收斂； 若 |g′(x*)| > 1，則發散（不動點是「排斥點」）。

用蜘蛛網圖看這個過程最清楚：在 (x, y) 平面畫出 y = g(x) 與 y = x， 從 (x₀, x₀) 出發，水平到曲線、垂直回到對角線，如此反覆——收斂的一步一步縮進交點，發散的則越跳越遠。

定點迭代 · 蜘蛛網動畫水平切到 g(x)、垂直彈回 y=x，看收斂或發散

03.2 牛頓法：用切線逼近根

牛頓法假設函數有一次近似：在 xₖ 處畫切線，切線與 x 軸的交點當作下一個猜測：

xₖ₊₁ = xₖ − f(xₖ) / f′(xₖ)

# 例子：求 √2，即 f(x)=x²−2
x₀ = 2
x₁ = 2 − (4−2)/4      = 1.5
x₂ = 1.5 − (1.25)/3   = 1.4166…
x₃ ≈ 1.4142156
x₄ ≈ 1.4142136  ← 已經接近 √2 = 1.41421356…

牛頓法的收斂速度是二次（正確位數約每步加倍），代價是每次要算導數 f′(x)。

牛頓求根 · 切線動畫綠色 = 函數、紅色切線 = 下一個猜測
與其他章節的關係
迭代法是最通用的「換一個更好猜測」框架：爬山法、梯度下降、PageRank、EM（課本 03 章）全都是在迭代。 差別只在「更新規則」怎麼設計——好的規則收斂快，壞的規則則震盪或爆炸。
