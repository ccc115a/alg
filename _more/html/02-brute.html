02 暴力法與列舉 窮舉一切可能，檢查哪一個正確

暴力法 (brute-force) 是最樸素的演算法：把所有可能的情況全部列出來，逐一檢查。它常常不是最快的，但永遠保證找得到答案——也因此是驗證其他演算法「對不對」的基準。

02.1 暴力法的精神

  1. 定義解空間：答案可能是哪些東西？（排列？組合？布林設定？）
  2. 系統化列舉：確保每個可能解都被拜訪到、且不重複。
  3. 逐一驗證：對每個候選解檢查它是否滿足條件。

生活中處處是暴力法：試密碼、窮舉牌型、比特幣挖礦就是一直試 SHA 雜湊值直到頭幾位是 0。

代價：解空間成長極快。n 個元素的排列有 n! 種、子集合有 2ⁿ 種。n=30 時連 2³⁰ ≈ 10⁹ 種都跑不完，所以暴力法通常只用在「小尺寸」問題。

02.2 真值表：列舉所有的布林設定

一個有 k 個變數的問題，可以用 2k 條真值表列舉出所有「開關組合」——這正是 SAT、密碼學中的窮舉搜尋空間。

真值表生成器列舉 k 個布林變數的 2ᵏ 種組合
組合數 = 8

02.3 排列：n! 種順序

「有幾種排法」就是排列數 n!。旅行推銷員問題要考慮所有拜訪順序，所以暴力解是 O(n!)。

排列生成器依序列舉 A、B、C… 的所有排列
排列數 = n! = 6

02.4 組合：C(n, r) 種選取

「從 n 個東西選 r 個（不管順序）」——例如開獎、抽樣、選擇題作答。

組合生成器從 0..n−1 中選 r 個元素（字典序）
組合數 = C(n,r) = 10

02.5 N 皇后：暴力列舉 + 檢查

經典習題：在 N×N 棋盤放 N 個皇后，讓她們互不攻擊（不同列、不同欄、不同對角線）。 暴力法把每個皇后隨意放進自己的那一列，窮舉 NN 種擺法，再一一檢查衝突—— 直到找到一個「合法解」。

for code in 0 .. N^N - 1:            # 把 code 解成每列的欄位
    cols = decode(code)              # 例如 N=4 時 code=114 → [1,3,0,2]
    if 無衝突(cols):                 # 不同欄 & 不同斜線
        return cols                  # 找到第一個解，結束
N 皇后 · 暴力搜尋動畫逐個列舉所有擺法，紅色 = 衝突
搜尋空間 Nᴺ = 256 種
觀察：N=4 只需要檢查 115 種擺法就找到第一個解；但 N=5 已是 3125 種、N=8 是 16,777,216 種。 這就是為什麼課本裡，N 皇后後續會改用「回溯法」(backtracking) 聰明的跳過整片不可能的擺法。
