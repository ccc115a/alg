06 分割擊破法 Divide & Conquer：拆小、解決、合併

把大問題切成幾個同類型的小問題，全部解決後再把結果合併——這是遞迴法最有力的應用。 合併排序、快速排序、二元搜尋，全都是這個框架。

06.1 三部曲

  1. 分割 (Divide)：把問題切成幾個同結構、但更小的子問題。
  2. 征服 (Conquer)：遞迴解決子問題；子問題夠小就直接解。
  3. 組合 (Combine)：把子問題的答案合併成原問題的答案。
主定理 (Master Theorem) 速記
若 T(n) = aT(n/b) + O(nc)，則 T(n) = O(nc log n) 當 a = bc（如合併排序：a=b=c=2 → O(n log n)）。

06.2 合併排序 Merge Sort：O(n log n)

把陣列砍半、砍半、再砍半，直到只剩一個元素（天然排好），再兩兩「合併」成有序陣列。

Merge Sort 動畫橘/綠 = 正在比較，綠底 = 已寫入位置

06.3 快速排序 Quick Sort：選基準、分兩邊

選一個「基準」(pivot)，把小的挪到左邊、大的挪到右邊，再遞迴排兩邊（這裡用 Lomuto 分割）。

Quick Sort 動畫紫 = 基準 pivot，黃 = 正在比對的元素

06.4 二元搜尋 Binary Search：每次砍掉一半

在已排序的陣列裡找目標：看中間元素，太大就往左、太小就往右，每次都刪掉一半——所以只要 O(log n)。

二元搜尋逐步示範黃 = low、藍 = mid、紫 = high

06.5 快速冪 Fast Exponentiation：把乘法次數壓到 log n

算 3¹³ 不用乘 13 次。把指數看成二進位 13 = 1101₂，邊讀位元邊「平方累乘」：

result = 1, base = x
對指數的每個位元（由左往右）：
    如果位元是 1 → result = result × base
    base = base × base          # 每步都平方
快速冪互動看 base 如何平方、result 如何累積
普通連乘需 e−1 次乘法，快速冪只要 2·⌈log₂e⌉+ 次。
