04 遞迴法 函數呼叫自己，把大問題拆成同樣結構的小問題

遞迴是演算法最重要的思考方式：假設「小一號的版本」已經會解決，那大問題只要一步就能變成小問題。 每個遞迴函數都必須有「基底情況」(base case)，否則永遠停不下來。

04.1 遞迴的骨架

def solve(n):
    if n 是基底情況:          # 1. 基底
        return 答案
    return 把 solve(n-1) 加工  # 2. 自我呼叫 3. 組合出答案

例：費氏數列 F(n)=F(n−1)+F(n−2)，河內塔、二元搜尋、Merge Sort 全都是這個骨架。

04.2 費氏數列：呼叫樹

看 fib(5) 的呼叫樹：fib(3)、fib(2) 被重複算了許多次——這就是「重疊子問題」，也是第 07 章動態規劃要解的痛點。

遞迴呼叫樹播放器會以「呼叫順序」逐個標亮節點
呼叫總數 25
已呼叫 正在執行 尚未呼叫

呼叫次數的差別

普通遞迴每個子問題重算一遍；記憶化 (memoization) 每個 fib(k) 只算一次 → 呼叫數從指數變「n 減 1 次」。

04.3 呼叫堆疊：一次只看一個「進行中」的呼叫

執行程式時，每呼叫一次就壓入一個「執行幀」(frame)，傳回後彈出。以 power(2,3)=2·power(2,2)=… 為例：

堆疊擴張與彈出power(x,n)=x·power(x,n−1)

04.4 河內塔：2ⁿ−1 步

把 n 個盤子從 A 移到 C，一次只搬一片，且大盤永遠不能壓在小盤上。 遞迴解：先搬 n−1 片到暫存柱 → 搬最大的到目標柱 → 再把 n−1 片搬上去。

def hanoi(n, A, B, C):            # 把 n 片 從 A 經由 B 搬到 C
    if n == 0: return
    hanoi(n-1, A, C, B)           # 1. 小盤全部去 B
    move(n, A, C)                 # 2. 最大的直接到 C
    hanoi(n-1, B, A, C)           # 3. 小盤再疊回 C
河內塔動畫總步數 = 2ⁿ − 1
最少步數 15
複雜度
time(hanoi(n)) = 2·time(hanoi(n−1)) + 1 = Θ(2ⁿ) — 但 n 只有幾十片時，最少步數本身就必須是這個量級。 遞迴真正的威力不在少算步數，而在「把寫程式變簡單」。
