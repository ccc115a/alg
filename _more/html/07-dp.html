07 動態規劃法 把重複的子問題記下來，從底部把答案堆起來

動態規劃 (DP) 專治「重疊子問題」：同樣的子問題一直被重算（像費氏數列的 fib(3) 被算好幾次）。 解法是從最小子問題開始，把答案一格一格填進表格，大的答案由小的堆疊出來。

07.1 兩個必要條件

  • 最佳子結構 (optimal substructure)：全域最佳解一定由子問題的最佳解組成。
  • 重疊子問題 (overlapping subproblems)：子問題被重複用到——才有記下來省錢的空間。

做法分成兩種：由上而下 + 記憶化 (memoization)，或由下而上 + 填表 (tabulation)。底下都用「填表」示範。

07.2 費氏數列：從 Θ(2ⁿ) 變成 Θ(n)

如果只存前兩個值，F(k)=F(k−1)+F(k−2) 可以一路滾上去。

費氏 · 填表動畫一格一格填入 F(0)…F(n)

左 = 純遞迴的呼叫數（指數），右 = DP 只需「每格填一次」（線性）。

07.3 0/1 背包：容量限制下的最大價值

有 n 個物品，每個只能拿或不拿一次（0/1），且總重量不能超過容量 W。定義

dp[i][w] = 只用前 i 個物品、容量 w 時能拿到的最大價值
dp[i][w] = max( dp[i-1][w],            # 不拿第 i 個
                dp[i-1][w - wi] + vi)   # 拿第 i 個（若 w ≥ wi）

格子填完後，從右下角沿著「改變」的路徑回溯，就知道該拿哪幾樣。

0/1 背包 · 填表動畫與回溯綠格 = 回溯選取的物品路徑

DP 最佳解 vs 貪婪解

貪婪依據「價值/重量」由大到小挑——常常很快，但不保證最佳。DP 一定最佳（這裡會看到差距）。

07.4 編輯距離：字串要多改幾次才一樣？

把字串 a 變成 b，允許的一系列操作：插入、刪除、取代各算 1 分，最少多少分？ dp[i][j] = 把 a 的前 j 字元變成 b 的前 i 字元所需的最少操作數。

若 a[j-1] == b[i-1]：dp[i][j] = dp[i-1][j-1]          （不用改）
否則：              dp[i][j] = 1 + min( dp[i-1][j-1],  # 取代
                                         dp[i][j-1],     # 插入
                                         dp[i-1][j]  )   # 刪除
編輯距離 · 填表與對齊綠徑 = 回溯出的最佳操作路徑

  






  
DP 的思考順序

  1) 定義「狀態」dp[…]；2) 寫出遞迴關係；3) 訂好初始值；4) 決定填表順序；5) 需要時做「回溯」取回方案。
