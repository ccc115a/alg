怎麼用這份教材

  1. 每一章都以明確的偽程式碼與「三步驟」拆解演算法的理論。
  2. 互動示範都在灰色卡片中，用下方播放器播放：▶︎ 播放、⟨⟩ 單步、拖曳時間軸跳到任意步驟。
  3. 可調整的參數（輸入大小、功能、速度…）會即時重算整個過程。
  4. 最後一章收錄了應用場景，示範演算法如何在真實世界的問題上落地。
