# 10 天寫出的 JavaScript

**領域**：數理邏輯與電腦史 | **年代**：1995 | **主角**：Brendan Eich | **相關**：[LISP](LISP.md)

---

**趣味點**：布蘭登·艾克（Brendan Eich）在網景公司被主管催命，只花了 10 天就蹭著當時最火的 Java 名字硬湊出了「JavaScript」。這兩個語言的關係就像「雷鋒與雷峰塔」，但這個 10 天趕工出來的語言現在成了網頁世界的絕對霸主。

1995 年，網景（Netscape）公司急需讓瀏覽器能執行互動程式碼。工程師布蘭登·艾克被指派完成使命——他只花了 **10 天**，就在 LiveScript 的基礎上設計出了初代 JavaScript。

當時 Java 正當紅（跨平台的物件導向語言），網景為了借勢行銷，硬把這個語言命名為 **JavaScript**——雖然兩者除了「名字像」之外幾乎沒任何關係，導致後人誤解兩者關係長達數十年（還有個經典梗：兩者的關係就像「雷鋒」與「雷峰塔」）。

但沒人料到：這個 10 天趕工、最初被視為小玩意的語言，如今是整個網頁世界的**絕對霸主**——從瀏覽器前端到 Node.js 後端、從手機 App 到桌面應用，JavaScript 無所不在。
