# 資料結構

資料結構是演算法的基礎容器。選擇正確的資料結構，往往比選擇正確的演算法更重要。本目錄收錄資料結構的歷史故事——從波音實驗室的磁碟困境到「玩具實驗」的意外成功。

> 基礎概念與程式實作可參見 [演算法/資料結構](../演算法/資料結構.md)。

## 技術解說

以下講解各種資料結構**如何運作**（不分歷史，純原理與適用情境）：

- [Inode](inode.md) - 檔案系統如何用一個索引節點描述檔案並指向資料區塊
- [B-Tree](B樹.md) - 多叉索引樹，磁碟資料庫的通用選擇
- [Bloom Filter](布隆濾波器.md) - 用一點點誤差換取巨大空間的「可能存在」濾波器
- [跳過表](跳過表.md) - 以機率堆疊替代平衡旋轉的有序結構
- [紅黑樹](紅黑樹.md) - 保證平衡的二元搜尋樹
- [Patricia Trie](Patricia樹.md) - 壓縮共同前綴的基數樹，IP 路由與自動完成的利器
- [SwissTable](swiss表.md) - Google 的高效能 SIMD 雜湊表
- [LSM 樹](LSM樹.md) - 寫入密集的 log-structured 合併樹
- [反向索引](反向索引.md) - 全文檢索（FTS）中的「詞 → 文件」對照與 BM25 排序
- [資料庫引擎](資料庫引擎.md) - KV、SQL、FTS、佇列如何由資料結構組裝成完整系統

> 連結串列、B-Tree、Bloom Filter、紅黑樹、跳過表的故事見上方「故事」表。
