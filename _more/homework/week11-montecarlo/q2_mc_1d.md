# q2：用蒙地卡羅法算單變數積分

**AI 聲明**：本程式與文件由 AI（opencode + GLM）協助產生，經人工檢視修改。

## 原理

把積分想成「平均面積」：

$$\int_a^b f(x)\,dx = (b-a)\cdot \overline{f}$$

其中 $\overline{f}$ 是 f 在 $[a,b]$ 上的平均值。蒙地卡羅法用「隨機取樣」估計這個平均值：

1. 在 $[a,b]$ 均勻隨機取 n 個點 $x_i$
2. 估計值 $= (b-a)\cdot \dfrac{1}{n}\sum_i f(x_i)$

誤差是 $O(1/\sqrt{n})$，與維度無關（這是蒙地卡羅在多維時的最大優勢）。

## 測試結果

```
n=1000    ∫₀¹ x² dx ≈ 0.3459 （正解 0.3333）
n=100000  ∫₀¹ x² dx ≈ 0.3341
∫₀^π sin x dx ≈ 2.0023 （正解 2）
```

可以看到取樣數越多越接近正解，且誤差大約以 $1/\sqrt{n}$ 的速度下降。
