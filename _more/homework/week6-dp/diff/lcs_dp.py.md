# lcs_dp.py — LCS 動態規劃 diff

## 用途

用最長共同子序列 (LCS) 的動態規劃產生兩字串的差異腳本。

## 函式

| 函式 | 說明 |
|---|---|
| `lcs_table(a, b)` | 回傳 LCS 長度表 `dp[i][j]` |
| `diff_lcs(a, b)` | 回溯產生 `('=',ch)` / `('-',ch)` / `('+',ch)` 操作列 |
| `format_diff(a, b)` | 格式化輸出 |

## 原理

兩字串的 diff 等價於求 LCS：LCS 中的字元保留（`=`），
不在 LCS 中的 `a` 字元刪除（`-`）、不在 LCS 中的 `b` 字元插入（`+`）。

## 狀態定義

```
dp[i][j] = a 的前 i 個字元與 b 的前 j 個字元的 LCS 長度
```

## 轉移方程

```
dp[i][j] = dp[i-1][j-1] + 1              若 a[i-1] == b[j-1]
         = max(dp[i-1][j], dp[i][j-1])   否則
```

## 初值

`dp[0][j] = dp[i][0] = 0`（空字串的 LCS 為 0）

## 回溯

從 `(n, m)` 出發：
- 對角線（字元相同且 `dp[i][j] == dp[i-1][j-1]+1`）→ 輸出 `=`
- 上方（`dp[i][j] == dp[i][j-1]`）→ 輸出 `+`（插入 b 的字元）
- 左方 → 輸出 `-`（刪除 a 的字元）

## 複雜度

- 時間 **O(nm)**
- 空間 **O(nm)**（回溯需整張表）

## 特性

- 保證產生最短編輯腳本（與 Myers 同樣最優）
- 缺點：不論兩檔多差異多小，都要填滿整張表——百萬行檔案不可行
