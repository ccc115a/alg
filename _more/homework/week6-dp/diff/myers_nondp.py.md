# myers_nondp.py — Myers O(ND) diff 演算法

## 用途

以最短路徑視角求兩字串的最短編輯腳本，是 `git diff` 等工具的核心演算法。

## 函式

| 函式 | 說明 |
|---|---|
| `myers_diff(a, b)` | 回傳 `('=',ch)` / `('-',ch)` / `('+',ch)` 操作列 |

## 原理（編輯圖最短路徑）

把 diff 建模成有向圖：
- 座標 `(x, y)` 代表「已處理 `a` 前 x 字元、`b` 前 y 字元」
- **向右** `(1,0)` = 刪除 `a[x]`
- **向下** `(0,1)` = 插入 `b[y]`
- **對角** `(1,1)`（僅當 `a[x]==b[y]`）= 相同，免費

起點 `(0,0)`，終點 `(n,m)`，求最少步數路徑。
設 `D` = 編輯次數，`D = n + m - 2·LCS`。

## 對角線優化

令 `k = x - y`（對角線編號）。對每個 `D`，只追蹤該層每個 `k`
**最右可達的 x**（`V[k]`）：
1. 選擇從 `k-1`（向右）或 `k+1`（向下）進入
2. 沿對角線「蛇行」延伸所有相同字元
3. 一旦 `(x,y) = (n,m)` 即找到答案

每層 D 只有 `2D+1` 條對角線 → 總計 O(ND) 次轉移。

## 回溯

存每層的 V 快照 `trace[d]`，從 `(n,m)` 反向走回 `(0,0)`：
- 比較 `trace[dd]` 中相鄰對角線的 x 判斷上一步方向
- 蛇行段全部輸出 `=`

## 複雜度

- 時間 **O(ND)**（D = 編輯次數，兩檔相似時 D ≪ n+m）
- 空間 **O(D²)**（回溯存每層快照；不回溯僅求 D 可壓到 O(D)）

## 特性

- 與 LCS DP 同樣保證最優
- 典型 diff 中 D 很小，實測比 LCS DP 快數倍（見 `main.py`）
- 這是「以 D 為參數的輸入敏感演算法 (parameterized/输出敏感)」
