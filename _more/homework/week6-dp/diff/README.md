# 1. diff — 兩個檔案差異比對

## 問題

給定兩個字串（或兩份檔案的行）`a`、`b`，找出把 `a` 變成 `b` 所需的最少插入/刪除操作，
並輸出差異腳本（`=` 相同、`-` 刪除、`+` 插入）。

## 解法一：LCS 動態規劃（`lcs_dp.py`）

### 原理

把 diff 化約為「最長共同子序列 (LCS)」問題：LCS 中的字元保留，其餘字元刪除或插入。

### 狀態與轉移

- `dp[i][j]` = `a` 前 `i` 字元與 `b` 前 `j` 字元的 LCS 長度
- `a[i-1] == b[j-1]` → `dp[i][j] = dp[i-1][j-1] + 1`
- 否則 → `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
- 回溯從 `(n,m)` 走回 `(0,0)` 產生 diff 腳本

### 複雜度

- 時間 **O(nm)**、空間 **O(nm)**（可壓至 O(min(n,m)) 但無法直接回溯）

### 缺點

不論兩檔多相似，都必須填完整張表；兩檔各一百萬行時需 10^12 格，不可行。

## 解法二：Myers O(ND) 演算法（非 DP，`myers_nondp.py`）

### 原理

在「編輯圖」上找最短路徑：向右 = 刪除、向下 = 插入、對角 = 相同。
設 `D` = 編輯次數（`D = n + m - 2·LCS`）。Myers 逐層擴展 `D`：
對每條對角線 `k = x - y` 只記錄最右可達點 `V[k]`，並沿相同字元「蛇行」延伸。
找到 `(n, m)` 時的 `D` 即為最短編輯次數。

### 複雜度

- 時間 **O(ND)**、空間 **O(D)**（實作上為回溯需存每層 V，O(D²) 或 O(D·min(n,m))）
- 典型 diff 中 `D ≪ n + m`（兩檔大部分相同），因此極快

## 比較

| | LCS DP | Myers O(ND) |
|---|---|---|
| 時間 | O(nm)，與差異量無關 | O(ND)，與差異量成正比 |
| 空間 | O(nm) | O(D)~O(D²) |
| 適用情境 | 小字串、需要 LCS 長度本身 | 大檔案、差異少（git diff 的作法） |
| 實作難度 | 簡單 | 中等（需回溯 V 快照） |

**結論**：DP 解法直觀、保證最優但空間爆炸；Myers 同樣保證最優，
且在「差異少」這個真實世界常見情形下快得多，故實際 diff 工具都用 Myers 一類演算法。
