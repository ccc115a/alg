# dp_comb.py — 動態規劃求 C(n,k)

## 用途

以 Pascal 公式的 DP 計算組合數 C(n, k)。

## 函式

| 函式 | 說明 |
|---|---|
| `comb_2d(n, k)` | 2D DP 表版，易懂 |
| `comb_1d(n, k)` | 1D 壓縮版，空間 O(k) |

## 原理

每個元素「取或不取」，得到遞推：

> 從 n 個取 k 個 = 取第 n 個（從前 n-1 取 k-1）+ 不取第 n 個（從前 n-1 取 k）

## 狀態定義

```
dp[i][j] = C(i, j) = 從 i 個取出 j 個的組合數
```

## 轉移方程（Pascal 公式）

```
C(n, k) = C(n-1, k-1) + C(n-1, k)
```

## 初值

```
C(i, 0) = 1    # 全不取
C(i, i) = 1    # 全取
```

## 1D 空間壓縮

只需一列 `dp[0..k]`，**由大到小**更新避免覆蓋：

```python
for i in range(1, n + 1):
    for j in range(min(i, k), 0, -1):
        dp[j] += dp[j - 1]   # dp[j] 舊值 = C(i-1,j)，dp[j-1] = C(i-1,j-1)
```

倒序是關鍵：`dp[j-1]` 必須是「上一列」的值。

## 複雜度

- 2D：時間 **O(nk)**、空間 **O(nk)**
- 1D：時間 **O(nk)**、空間 **O(k)**

## 特性

- 每個 `(i, j)` 只算一次——消除了純遞迴的指數重複計算
- 大數時中間值快速膨脹（Python 自動 big-int，無溢位但變慢）
- 需要取模時此 DP 是標準作法；需要單一精確值時階乘公式更快
  （見 `recurse_comb_nondp.py` 的 `comb_factorial`）
