## 1. 問題定義

給定 $n$ 個城市與任兩城市間的距離，求一條**每個城市恰好造訪一次、最後回到起點**的最短路徑（哈密頓迴路）。

設一條路徑為城市的排列 $\pi = (\pi_0, \pi_1, \dots, \pi_{n-1})$，其長度為：

$$
L(\pi) = \sum_{k=0}^{n-1} d\big(\pi_k,\ \pi_{(k+1) \bmod n}\big)
$$

可能的路徑共有 $(n-1)!/2$ 條（對稱 TSP），$n=20$ 時約 $6 \times 10^{16}$ 條，無法暴力窮舉，因此需要啟發式方法（heuristics）在合理時間內找到「夠好」的解。

對應程式：

```python
def tour_length(tour):
    return sum(DIST[tour[i], tour[(i + 1) % len(tour)]] for i in range(len(tour)))
```

`(i + 1) % len(tour)` 讓最後一個城市接回第一個城市，形成封閉迴路。

## 2. 測試資料

```python
N_CITIES = 20
rng = random.Random(42)
CITIES = [(rng.uniform(0, 100), rng.uniform(0, 100)) for _ in range(N_CITIES)]
DIST = np.array([[math.dist(a, b) for b in CITIES] for a in CITIES])
```

- 20 個城市，座標在 $[0,100]\times[0,100]$ 內均勻分布。
- 固定亂數種子 `42`，所以每次執行資料完全相同，**五種方法面對的是同一個問題**。
- `DIST` 為預先計算的 $20\times20$ 歐氏距離矩陣（對稱、對角線為 0），之後查表即可，不必重複開根號。

## 4. 各演算法原理與實作

### 4.1 貪婪演算法（最近鄰居法，Nearest Neighbor）

**原理**
從起點出發，每一步都走向「目前位置最近、且尚未造訪」的城市，直到全部走完再回到起點。

**特性**
- 每一步都做**局部最優**選擇，但從不回頭修正，所以整體不保證最佳。
- 前期路徑通常很漂亮，但後期剩下的城市可能散落各處，被迫走很長的回頭路（圖中 16 號城市附近的大迴繞就是典型例子）。
- 速度極快，常被當作其他演算法的**初始解**。

**實作**

```python
def greedy(start=0):
    unvisited = set(range(N_CITIES)) - {start}
    tour = [start]
    while unvisited:
        nxt = min(unvisited, key=lambda c: DIST[tour[-1], c])
        tour.append(nxt)
        unvisited.remove(nxt)
    return tour
```

### 4.2 改良法（2-opt）

**原理**
先取得一條可行路徑（本程式用貪婪解），再反覆對它做**局部改良**：

> 取出路徑中的兩條邊 $(a,b)$ 與 $(c,d)$，把中間那一段**反轉**，使其變成 $(a,c)$ 與 $(b,d)$。若新路徑更短就採用。

```
改良前:  … a → b → … → c → d …
改良後:  … a → c → … → b → d …   （b 到 c 之間的順序被反轉）
```

交叉的兩條邊一定可以透過 2-opt 變短（三角不等式），所以 2-opt 能夠**消除路徑上的交叉**。

**不必重算整條路徑長度**：反轉前後只有兩條邊改變，所以變化量為

$$
\Delta = d(a,c) + d(b,d) - d(a,b) - d(c,d)
$$

$\Delta < 0$ 代表改善。

**本程式的策略：最佳改善（best-improvement）**
每一輪掃過**所有** $(i, j)$ 組合，挑出 $\Delta$ 最小（改善最多）者執行；重複直到找不到任何 $\Delta<0$ 的組合，此時抵達 **2-opt 局部最佳解**。

**實作重點**

```python
for i in range(n - 1):
    for j in range(i + 2, n):
        if i == 0 and j == n - 1:      # 這兩條邊在環上相鄰，反轉無意義
            continue
        a, b = tour[i], tour[i + 1]
        c, d = tour[j], tour[(j + 1) % n]
        delta = DIST[a, c] + DIST[b, d] - DIST[a, b] - DIST[c, d]
        ...
tour[i + 1:j + 1] = reversed(tour[i + 1:j + 1])   # 反轉 b…c 這一段
```

**特性**
- 確定性：相同輸入必得相同輸出。
- 品質通常比貪婪好很多，實務上常是「貪婪 + 2-opt」的標準組合。
- 仍可能停在局部最佳解，無法保證全域最佳。

---

### 4.3 爬山演算法（Hill Climbing）

**原理**
把「路徑長度」想成地形高度，目標是走到最低的谷底。流程：

1. 隨機產生一條初始路徑。
2. 隨機挑兩個城市**交換位置**，得到鄰居解。
3. 若鄰居**比較短**就接受，否則**還原**。
4. 重複固定次數。

**實作**

```python
for _ in range(iters):                       # iters = 20000
    i, j = r.sample(range(N_CITIES), 2)
    tour[i], tour[j] = tour[j], tour[i]      # 交換
    new = tour_length(tour)
    if new < cur:
        cur = new                            # 接受
    else:
        tour[i], tour[j] = tour[j], tour[i]  # 還原
```

**特性與缺點**
- 只接受「更好」的解，所以一旦走到某個**局部最低點**（任何單次交換都無法改善），就再也出不來。
- 本程式的鄰域是「交換兩個城市」，比 2-opt 的「反轉一段」改動更粗糙，不易直接消除交叉邊，因此結果最差。
- 與 2-opt 不同的是：這裡每次只**隨機抽一個**鄰居，而非檢查全部鄰居。

### 4.4 模擬退火法（Simulated Annealing, SA）

**原理**
源自金屬退火：高溫時原子活躍、容易跳出不良結構；緩慢降溫後逐漸穩定於低能量狀態。對應到最佳化：

- 「能量」＝ 路徑長度
- 「溫度 $T$」＝ 容忍變差的程度

**接受準則（Metropolis criterion）**
產生鄰居解後，令 $\Delta = L_{\text{new}} - L_{\text{cur}}$：

$$
P(\text{接受}) =
\begin{cases}
1 & \Delta < 0 \quad(\text{變好，一定接受})\\[4pt]
e^{-\Delta / T} & \Delta \ge 0 \quad(\text{變差，依機率接受})
\end{cases}
$$

- **$T$ 大**：$e^{-\Delta/T}\approx 1$，幾乎什麼都接受 → 像隨機漫步，廣泛探索。
- **$T$ 小**：$e^{-\Delta/T}\approx 0$，幾乎只接受變好的 → 退化為爬山，精細收斂。
- 因為有時會接受較差解，SA 才**有機會逃離局部最佳解**。

**本程式參數與流程**

| 參數 | 值 | 意義 |
|------|----|------|
| `T0` | 100 | 初始溫度 |
| `T_end` | 1e-3 | 終止溫度 |
| `alpha` | 0.995 | 降溫係數，每個溫度後 $T \leftarrow \alpha T$（幾何冷卻） |
| `per_temp` | 100 | 每個溫度下嘗試的次數 |

溫度階數約為 $\ln(10^{-5})/\ln(0.995)\approx 2300$，總迭代約 23 萬次。

```python
while T > T_end:
    for _ in range(per_temp):
        i, j = sorted(r.sample(range(N_CITIES), 2))
        cand = tour[:i] + tour[i:j+1][::-1] + tour[j+1:]   # 2-opt 鄰域：反轉 i..j
        d = tour_length(cand) - cur
        if d < 0 or r.random() < math.exp(-d / T):
            tour, cur = cand, cur + d
            if cur < best_len:                              # 持續記錄歷史最佳
                best, best_len = tour[:], cur
    T *= alpha
return best
```

**實作細節**
- 鄰域採用「反轉區段」(2-opt move) 而非交換，品質較佳。
- 另外保存 `best`：退火過程中當前解可能變差，最後回傳的是**曾經出現過的最佳解**。
- `T0` 要與距離尺度匹配（本資料典型邊長約 10～50，故 100 足夠高）。

### 4.5 梯度下降法（Gradient Descent）

這是五種方法中最特別的一個。

#### 為什麼需要「連續鬆弛」？

梯度下降需要**可微分的連續函數**，而 TSP 的解是離散的排列，無法直接求導。解法是**連續鬆弛（continuous relaxation）**：把「硬性的 0/1 指派」放寬成「機率式的軟指派」，用梯度優化之後，再**解碼**回合法排列。

#### 變數設計

令 $P \in \mathbb{R}^{n\times n}$，其中 $P_{k,i}$ 表示「**第 $k$ 步造訪城市 $i$ 的機率**」。
若 $P$ 是排列矩陣（每列、每欄恰一個 1），它就對應一條合法路徑。

為了保證**每一列總和為 1**（每個位置必有一個城市），不直接優化 $P$，而是優化無約束參數 $W$ 並令：

$$
P_{k,\cdot} = \text{softmax}(W_{k,\cdot})
$$

#### 目標函數

**(1) 期望路徑長度**（環狀，所以 $k+1$ 取模 $n$）：

$$
L(P) = \sum_{k=0}^{n-1} P_{k,\cdot}\; D\; P_{k+1,\cdot}^{\top}
$$

意義：位置 $k$ 在城市 $i$、位置 $k+1$ 在城市 $j$ 的機率乘上 $d_{ij}$，加總即為期望距離。

**(2) 懲罰項**：softmax 只保證「每一列」和為 1，不保證「每個城市恰好出現一次」，所以加入

$$
R(P) = \lambda \sum_{i=0}^{n-1}\Big(\sum_{k} P_{k,i} - 1\Big)^2
$$

總損失： $`\;\mathcal{L} = L(P) + R(P)`$。

程式中將 $D$ 除以其平均值（`Dn = DIST / DIST.mean()`），讓 $L$ 與 $R$ 的量級接近，避免梯度爆炸或被懲罰項淹沒。

#### 梯度推導

因 $D$ 對稱：

$$
\frac{\partial L}{\partial P_{k,\cdot}} = D\,P_{k+1,\cdot} + D\,P_{k-1,\cdot}
$$

懲罰項：

$$
\frac{\partial R}{\partial P_{k,i}} = 2\lambda\Big(\sum_{k'} P_{k',i} - 1\Big)
$$

再經 softmax 反向傳播（對每一列）：

$$
\frac{\partial \mathcal{L}}{\partial W_{k,i}} = P_{k,i}\Big(g_{k,i} - \sum_j g_{k,j}P_{k,j}\Big),\qquad g = \frac{\partial \mathcal{L}}{\partial P}
$$

對應程式：

```python
P   = softmax(W)
nxt, prv = np.roll(P, -1, axis=0), np.roll(P, 1, axis=0)   # P[k+1], P[k-1]
gP  = nxt @ Dn + prv @ Dn                                   # ∂L/∂P
col = P.sum(axis=0) - 1.0
gP += 2 * lam * col[None, :]                                # 加上懲罰項梯度
gW  = P * (gP - (gP * P).sum(axis=1, keepdims=True))        # softmax 反向傳播
W  -= lr * (1 - t / steps * 0.9) * gW * 10                  # 梯度下降更新
```

#### 學習率

`lr * (1 - 0.9 * t/steps) * 10`：從 0.5 線性衰減到約 0.05。前期大步探索、後期小步收斂。

#### 解碼（Decoding）

優化結束後 $P$ 通常接近但不等於排列矩陣。本程式採**貪婪解碼**：

```python
for _ in range(n):
    k, i = np.unravel_index(np.argmax(Pm), Pm.shape)  # 找全矩陣最大機率的 (位置, 城市)
    tour[k] = i
    Pm[k, :] = -1;  Pm[:, i] = -1                     # 該位置與該城市都不能再用
```

每次取機率最大的配對，並封鎖其所在的列與欄，重複 $n$ 次即得合法排列。（嚴謹做法可用匈牙利演算法 `scipy.optimize.linear_sum_assignment` 做最佳指派。）

#### 特性與限制

- 損失函數**非凸**，只能保證收斂到局部極小，且依賴初始值（`seed`）。
- 超參數（`lr`、`lam`、`steps`）敏感：`lam` 太小會出現重複城市傾向，太大會壓過距離項。
- 變數數量為 $n^2$，規模增大時比其他方法更吃資源。
- 本實作**不**在解碼後再接 2-opt，因此展現的是「梯度下降本身」的能力。

## 5. 執行結果與分析

同一組資料（20 城市、seed=42）的一次執行結果：

| 方法 | 路徑長度 | 耗時 |
|------|---------:|-----:|
| 1. 改良法（2-opt） | **352.32** | ≈ 0.001 s |
| 2. 爬山演算法 | 497.19 | ≈ 0.13 s |
| 3. 模擬退火法 | **352.32** | ≈ 1.9 s |
| 4. 梯度下降法 | 412.34 | ≈ 0.26 s |
| 5. 貪婪演算法 | 460.51 | ≈ 0 s |

> 耗時依機器而異；上表僅供相對比較。

**觀察**

1. **改良法與模擬退火法最佳（352.32）**，路徑形狀相同且無交叉邊。
2. **改良法在此資料上 CP 值最高**：從貪婪解出發，毫秒內就達到與耗時近 2 秒的模擬退火相同的品質。
3. **爬山演算法最差**：鄰域（交換）較粗糙，且完全不接受變差的解，容易卡在局部最佳。
4. **貪婪演算法**雖快，但留下明顯的長距離回頭路，品質低於改良法。
5. **梯度下降法**介於中間：比貪婪與爬山好，但不如 2-opt 與 SA，且結果與超參數、種子相關。

> ⚠️ 以上是**單一資料集、單次執行**的結果。隨機式方法（爬山、SA、梯度下降）換 `seed` 結果會變動；城市數增加時，各方法的相對表現也可能改變。要得到可靠結論，應使用多組資料與多個 seed 取平均。

## 6. 複雜度比較

設 $n$ 為城市數。

| 方法 | 單次評估/步驟成本 | 總時間複雜度 | 是否隨機 | 能否逃離局部最佳 |
|------|------------------|--------------|:-------:|:----------------:|
| 貪婪 | 每步掃描未訪問城市 | $O(n^2)$ | 否 | — （一次建構） |
| 2-opt 改良 | 每輪掃描 $O(n^2)$ 個鄰居 | $O(R\cdot n^2)$，$R$ 為改善輪數 | 否 | 否 |
| 爬山 | 重算路徑長度 $O(n)$ | $O(I\cdot n)$，$I$ 為迭代次數 | 是 | 否 |
| 模擬退火 | 重算路徑長度 $O(n)$ | $O(I\cdot n)$，$I\approx 2.3\times10^5$ | 是 | 是（機率接受差解） |
| 梯度下降 | 矩陣乘法 $O(n^3)$ | $O(S\cdot n^3)$，$S$ 為步數 | 是（初始化） | 部分（取決於初始與步長） |

補充：本程式的爬山與 SA 為了簡單，每次都完整重算 `tour_length`（$O(n)$）。若只重算變動的邊（如 2-opt 的 $\Delta$ 公式），單次評估可降到 $O(1)$，大規模問題會快很多。

## 7. 參數調整建議

| 目標 | 建議 |
|------|------|
| SA 想更精確 | 提高 `alpha`（如 0.999）、增加 `per_temp`，代價是更慢 |
| SA 結果不穩 | 提高 `T0`，或嘗試多個 `seed` 取最佳 |
| 爬山想改善 | 增加 `iters`；或改用「多次隨機重啟」取最佳 |
| 梯度下降不收斂／有重複城市傾向 | 調整 `lam`（懲罰強度）、`lr`、`steps`；嘗試多個 `seed` |
| 換資料 | 修改 `N_CITIES` 與 `random.Random(42)` 的種子；或直接把 `CITIES` 換成自己的座標列表 |

使用自己的座標：

```python
CITIES = [(x1, y1), (x2, y2), ...]
N_CITIES = len(CITIES)
```

## 8. 限制與延伸

**限制**
- 所有方法皆為**啟發式**，無法證明解為全域最佳。
- 距離使用歐氏距離；若為非對稱距離（如單行道），梯度下降中 $D$ 對稱的假設與 2-opt 的 $\Delta$ 公式需調整。
- 梯度下降為教學用途的鬆弛實作，實務上並非 TSP 的主流解法。

**可延伸的方向**
1. **Or-opt / 3-opt / Lin–Kernighan**：更強的區域搜尋。
2. **多起點 + 2-opt**：以不同起點的貪婪解各自改良，取最佳。
3. **爬山法隨機重啟**（random restart）。
4. **基因演算法、蟻群演算法、Christofides 演算法**：其他經典做法。
5. **精確解法**：Held–Karp 動態規劃（$O(n^2 2^n)$，約適用 $n\le 20$ 左右）可用來驗證本資料的真正最佳解，作為基準。
6. 用匈牙利演算法取代梯度下降的貪婪解碼，或在解碼後接 2-opt 做後處理。
