# 其他經典

不在上述分類，但同樣充滿戲劇性的演算法故事。從賭場黑名單到百萬美元的數學難題，這些故事展示了演算法世界的多樣風貌。

| [Karmarkar](../algorithms/karmarkar.md) | 1984 | 差點被列為軍事機密 |
| [Gale-Shapley](../algorithms/gale-shapley.md) | 1962 | 諾貝爾獎的「相親演算法」 |
| [蟻群演算法](../algorithms/ant-colony.md) | 1992 | 螞蟻的費洛蒙智慧 |
| [NP 完全性](../algorithms/np-completeness.md) | 1971 | 證明「不可能」的終極邊界 |
