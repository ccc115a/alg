# 肯·湯普森的魔鬼編譯器：連原始碼都查不出後門

**領域**：[數理邏輯與電腦史](../categories/history.md) | **年代**：1984 | **主角**：Ken Thompson

---

**趣味點**：肯·湯普森在圖靈獎頒獎典禮上拋出一個讓全場安全專家倒吸一口涼氣的核彈：他曾在 C 語言編譯器裡寫了後門，這個後門能自動在編譯過程中把後門複製到目標軟體——即使你把原始碼查個底朝天，也查不出任何問題。

1984 年，[UNIX](../algorithms/unix.md) 與 C 語言之父肯·湯普森（Ken Thompson）在圖靈獎演講中，發表了一篇比得獎致詞更震撼的演講（《Reflections on Trusting Trust》）。

他透露：他曾在 C 語言編譯器裡植入一個「會自我複製的後門」：

1. 當編譯器編譯**其他程式**時，會偷偷把後門程式碼寫進去；
2. 更可怕的是，當編譯器去編譯「編譯器自己」時，連「植入後門」的這段邏輯也會一起編進去；
3. 結果就是——**即使你把編譯器原始碼裡的後門徹底刪除**，重新編譯出來的編譯器依然帶有後門。

**這意味著：絕對的軟體安全並不存在。**因為你永遠無法 100% 信任「產生軟體的工具」。這篇演講被譽為電腦安全史上最毛骨悚然的黑科技心靈震撼。
