# 404 Not Found 的都市傳說

**領域**：[數理邏輯與電腦史](../categories/history.md) | **年代**：1994 | **相關**：[全球資訊網](www.md)

---

**趣味點**：網路上盛傳「404 錯誤碼是因為 CERN 的 404 號房間放著第一台 Web 伺服器，去找檔案找不到就叫 404」。雖然網頁創始人出來闢謠說這純屬胡扯（只是 HTTP 協定隨機排號），但這個都市傳說至今大家依然深信不疑。

每個網路使用者都碰過「404 Not Found」——網站找不到你要的頁面時顯示的錯誤訊息。

多年來，網路上流傳一個浪漫的都市傳說：CERN 的 404 號房間存放著第一台 Web 伺服器，所以「找不到頁面」就以這個房間號命名。

事實是：網頁技術創始人提姆·柏內茲-李與 HTTP 協定設計者都出來證實，**純屬巧合**。404 只是 HTTP 狀態碼「4xx（用戶端錯誤）＋04（找不到）」的標準編號分組而已。

但「404 號房」的傳說依然生龍活虎地在全世界的普及文化中流傳——有些解釋比真相更美，經典有時真的不需要是事實。
